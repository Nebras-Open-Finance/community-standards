# Release Notes

Release Notes record changes to the **operational systems** that participants integrate with — the API Hub platform, the Trust Framework, and any supporting infrastructure. Each entry describes what was deployed, when it became effective, and the impact on TPPs and LFIs.

Release Notes are organised by component, then by calendar year. Within each year, entries are listed newest first.

## API Hub

Deployments to the API Hub platform — the OIDC authorization server, Consent Manager, gateway, and resource server that fronts every LFI.

- [API Hub — 2026](./api-hub/2026)

## Trust Framework

Releases of the Trust Framework directory — the participant directory, certificate authority, and source of role and scope truth. Delivered by Raidiam.
