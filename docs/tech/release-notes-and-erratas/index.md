# Release Notes & Erratas

This section tracks post-publication changes to the UAE Open Finance ecosystem. It is split into two registers:

## Release Notes

Record changes to the **operational systems** that participants integrate with — the API Hub platform, the Trust Framework, and any supporting infrastructure. Each entry describes what was deployed, when it became effective, and the impact on TPPs and LFIs.

Use Release Notes to understand:

- What was deployed to the API Hub or Trust Framework, and when
- Whether a change affects your implementation or behaviour you depend on
- Which tickets drove the change

Release Notes are organised by component (**API Hub**, **Trust Framework**) and then by calendar year.

## Erratas

Record corrections to **published documentation** — the TPP Standards, LFI Integration Guide, and OpenAPI specifications. Each entry records what was corrected, why, and the effective date.

Use Erratas to understand:

- What changed in the documentation for a given standard version
- Why the correction was needed
- When the corrected text took effect

Erratas are organised by standard version (e.g. `v2.1`).
