# Consent Approval Application Platform (CAAP)

::: warning Coming Soon
This section is under development. Content will be added in a future update.
:::

The **Consent Approval Application Platform (CAAP)** is an API Hub-hosted solution for managing the PSU consent approval journey. LFIs that choose to use CAAP delegate the consent approval user experience to the API Hub rather than building and hosting their own consent screens.

Whether to use CAAP is indicated during the [prerequisites onboarding](/tech/lfi-api-hub/v2.1/api-hub/onboarding/prerequisites#caap) process.
