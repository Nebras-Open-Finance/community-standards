# TPP Standards

These specifications describe the APIs the API Hub exposes to **TPPs** (Third-Party Providers). They show the request and response contracts a TPP integrates against when building an Open Finance application — covering Trust Framework discovery, registration, token exchange, consent, bank data sharing, service initiation, confirmation of payee, ATMs, and event notifications.

**Audience:** TPP engineering teams building applications against the UAE Open Finance platform.

**What you'll find here:** the endpoints a TPP calls directly, and the responses it should expect from the API Hub.
